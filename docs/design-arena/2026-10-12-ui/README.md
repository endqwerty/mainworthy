# The UI arena, 2026-10-12

Three candidates each built an interactive mock of the hot paths (capture a case, run a suite, answer the queue)
from one brief, each starting from a different idea of the screen. The decision that came out of it is
[0011](../../decisions/0011-ui-direction.md).

| File | What |
| --- | --- |
| [brief.md](brief.md) | What every candidate had to build: the three jobs, the data, the keys |
| [rubric.md](rubric.md) | The judge's criteria. The candidates did not see it |
| [candidates/u1](candidates/u1) | One outline: the whole suite as one folded document (GPT 6.1 Sol) |
| [candidates/u2](candidates/u2) | The workbench: sidebar, dense list, pane (Claude Opus 5.5) |
| [candidates/u3](candidates/u3) | The document: a calm page you type into (GPT 6.1 Sol) |
| [verdict.md](verdict.md) | The cross-judge's verdict (GPT 6 Astra): it drove each mock with real key events, counted keys and visible rows, and scored them |
| [judge-frozen-manifest.json](judge-frozen-manifest.json) | The hashes of the files the judge looked at |

Each candidate directory holds the mock (`index.html`, open it in a browser), the candidate's rationale and
screenshots. The mocks run on seeded data in the page; they are not the product.
