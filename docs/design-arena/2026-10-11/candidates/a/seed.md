## Your seed lens (candidate A)

Start from this whole-shape idea and push it as far as it goes; abandon it only if you can show it breaks, and say so:

**Evidence-stream centric.** The primitive is the *result event*: an immutable fact that some actor (person, CI runner, agent) observed some outcome against some expectation at some version of the software at some time. A "test case" is an addressable expectation; a "run" is a query over events; "automated vs manual vs agentic" is just the actor kind on the event. Flakiness, coverage, gates, traceability and the agent's impact set are all derived views over the stream and the link graph. The product's UI is a fast client over expectations and the evidence that proves them.
