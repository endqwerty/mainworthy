# Diagram sources

The three diagrams in `docs/diagrams/` are generated by [archify](https://github.com/tt-a1i/archify) from the
candidates in this directory. Each candidate names the repository revision its source links point at.

| Diagram | Candidate | archify type |
| --- | --- | --- |
| `architecture.html` | `architecture.json` | `architecture` |
| `red-build.html` | `red-build.json` | `sequence` |
| `question-lifecycle.html` | `question-lifecycle.json` | `lifecycle` |

To regenerate one after the code it describes has changed: edit the candidate, set `meta.repository.revision` to
a commit that is on GitHub, then in the `archify` directory of a checkout of archify run

```
node bin/archify.mjs finalize <type> <candidate.json> <output.html> --repo-root <this repository> --quality showcase --json
```

`finalize` validates the candidate against the files it cites, renders it and checks the page in a browser. The
`.png` beside each page is a screenshot of it, for places that do not render HTML (a pull request description).
