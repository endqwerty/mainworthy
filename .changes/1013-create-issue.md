Failure questions in the queue and case history can create an issue in the configured tracker. Review the evidence before sending, then read the issue link or delivery error. The action is also available from the keyboard and palette. The review shows the server’s exact destination, title and body. Sending checks a confirmation digest and refuses a changed destination or payload until reviewed again. CLI creation without a review remains available.
