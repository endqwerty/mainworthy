Writes to different projects can run concurrently. A report releases its project and actor locks after acceptance and rechecks the admitting token or browser session and current authority before application or recovery. A revoked report is cancelled and stops holding runs pending. Lock contention and PostgreSQL deadlocks return retryable `busy` replies with HTTP 503. Retry unchanged content with the same command id. Already accepted reports remain pending until application or cancellation. The browser keeps pending requests and the CLI reports `busy` with exit code 4. The API version advances to 3. Clients pinned to API 1 or 2 must upgrade before writing.
